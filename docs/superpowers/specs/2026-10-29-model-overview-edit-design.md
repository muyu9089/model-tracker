# 模型总览编辑设计

## 目标与范围

在现有“模型总览”的每个模型行增加编辑功能。可修改模型名称、所属组织、开源状态、所属地域，以及该行各评测项的分数。保存后立即写入 SQLite 并刷新页面。其它原始数据表仍用于查看。

## 方案

- **行内编辑（建议）**：点击“编辑”后将该行相关单元格变成输入框，提供“保存”“取消”。能边看评测项边改分数，改动集中在现有页面。
- **弹窗编辑**：表格较整洁，但填写多个评测项时需要在弹窗与表格之间切换。

采用行内编辑。沿用页面现有操作令牌，新增受令牌保护的 `PUT /models/{id}`。服务端只接受上述字段，校验模型名称非空且不与其它模型重复、评测项代码有效、分数为有限数字或空值；一次事务更新名称、资料与分数。空白资料和分数表示清空对应值，资料其它字段及评测结果的匹配来源保持原值。无分数的评测状态标记为待补充，有分数标记为已记录。

## 边界

不开放其它数据表或评测来源元数据编辑；不用新依赖。保存失败时保留当前输入并显示错误，不写入部分改动。现有删除和补充操作继续使用相同令牌。
