# 模型总览设计

## 目标

在现有数据库查看页增加“模型总览”菜单，方便逐个查看库中所有模型的名称、评测项及结果、所属组织、开源状态和所属地域。每个模型占一行。

## 方案

- 采用：在现有 `/` 页面加入菜单和只读总览表，复用 `TrackerRepository.rows` 与现有 HTML/CSS；无需额外服务或依赖。
- 考虑过：新建独立页面。用户选择复用现有页面，导航更集中，改动也更小。

## 展示规则

从 `models` 左连接 `model_profiles`，从 `benchmarks`、`benchmark_results` 读取各项评测与分数。没有资料或分数时显示“—”；评测项仍列出。动态 HTML 内容按现有 `_cell` 转义。总览展示所有模型，原始表菜单及其每表 200 行限制保持原样。

## 验证

用临时 SQLite 测试多个模型、有无资料及评测结果、HTML 转义与菜单切换，并运行受影响的页面测试。
